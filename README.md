# When Accurate Prerequisite Graphs Are Not More Useful

Code, notebooks and result files for the article:

> Z. Elkaimbillah, S. Miqoi, M. Khoual, and M. Elhamlaoui, "When Accurate Prerequisite Graphs Are Not More Useful: Disentangling Structural Quality and Predictive Utility in Knowledge Tracing," submitted to *IEEE Transactions on Learning Technologies*.

## What the study does

The study separates two properties of a prerequisite graph used in knowledge tracing (KT):

- **structural fidelity**: how well the graph agrees with expert prerequisites (ROC AUC, AUPRC, top-K precision);
- **predictive utility**: how much the graph improves the first-attempt AUC of a KT model.

It compares expert graphs, graphs generated by two LLMs (Qwen2.5-7B-Instruct, Llama-3.1-8B-Instruct), random controls and graphs learned end-to-end by a KT model, on Junyi Academy, DBE-KT22 and simulated learners.

## Data

The raw datasets are not redistributed. Download them from their original sources and place them in the Google Drive folder set in the first cell of each notebook:

- **Junyi Academy (2015)**: PSLC DataShop, dataset 1198 (Chang, Hsu and Chen, EDM 2015).
- **DBE-KT22**: Abdelrahman et al., arXiv:2208.12651, and the dataset repository linked there.
- **Simulation**: generated by `etape17c_simulation.ipynb`.

## Requirements

Python 3, PyTorch, NumPy, pandas, scikit-learn, SciPy, statsmodels, networkx, matplotlib, transformers and bitsandbytes (for LLM scoring). The notebooks were run on Google Colab with an NVIDIA T4 GPU. Llama-3.1-8B-Instruct requires accepting the model licence on Hugging Face and a token stored in the Colab secrets as `HF_TOKEN`.

## Reproducing the results

Run the notebooks in order. Each notebook saves its results to the Google Drive folder set in its first cell and resumes after a disconnection. Long experiments are split into parts (`PARTIE = 'A'` / `'B'`) that can run on two Colab accounts in parallel. To redraw the figures:

```
python figures/make_figs.py <results folder> <output folder>
```
