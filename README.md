# Prerequisite Graphs in Knowledge Tracing

Code and result files accompanying a manuscript prepared for submission.

## Contents

- `notebooks/` – experiment notebooks (Google Colab), numbered by step (`etape2` to `etape18`)
- `results/` – result files (CSV), one folder per step
- `figures/make_figs.py` – script that draws the figures from the result files

## Data

The datasets are not included. Download them from their original providers:

- Junyi Academy 2015 (PSLC DataShop, dataset 1198)
- DBE-KT22 (Abdelrahman et al., arXiv:2208.12651)

The simulated data are generated by `etape17c_simulation.ipynb`.

## How to reproduce

1. Upload the datasets to a Google Drive folder and set its path in the first cell of each notebook.
2. Run the notebooks in numerical order on Google Colab with a T4 GPU. Each notebook saves its results to the Drive folder and resumes after a disconnection.
3. Run `python figures/make_figs.py <results folder> <output folder>` to redraw the figures.

Main libraries: Python 3, PyTorch, NumPy, pandas, scikit-learn, SciPy, statsmodels, networkx, matplotlib, transformers, bitsandbytes. LLM scores use Qwen2.5-7B-Instruct and Llama-3.1-8B-Instruct (Hugging Face) in 4-bit precision; the exact prompt is in `etape9_rq1_rq2_graphe_llm.ipynb` (cell B2) and `etape16_deuxieme_llm_llama.ipynb` (cell E1).
